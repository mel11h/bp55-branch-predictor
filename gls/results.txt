Cell models (gls/mkcells.py, gls/cellcheck.py)
  The PDK Verilog builds flops and muxes from UDP tables (udp_dff, udp_mux2, udp_mux4, ipicg_latchnsr),
  has specify blocks with $setuphold/$width and a NOTIFIER reg per flop, and the ICG cells clock their
  latch from dly_CK / dly_E, nets that only a $setuphold delayed-signal argument drives. Filler and tap
  cells (FILLER*, FILLTAPH7R) have no Verilog model at all.
  For Yosys / Verilator: UDPs replaced by behavioural modules of the same name and ports, anonymous UDP
  instances named, specify blocks removed, dly_* tied to the pins, fillers as empty modules.
  For Icarus: the unmodified PDK file, except dly_* tied to the pins (Icarus 12: "Timing checks are not
  supported and delayed signal ... will not be driven", so the original ICG output is X forever).
  Proof of the translation: 551 used cells, original (Icarus, UDPs) vs translated, random 2-state
  stimulus, 4000 vectors per cell, 2,203,986 compared points, 0 mismatches (logs/cellcheck.log).

Tool problems found on the way (each reproduced on a 3-flop test design)
  1. Yosys 0.69 write_cxxrtl, $dffsr (async set + reset, what the UDP flop model is before constant
     folding): emits "q.next = q.curr.update(...)" after the clocked "q.next = d" and so discards every
     clocked update; all flops hold their value. Found because the gate-level co-simulation failed its
     own post-reset clear check (busy-length 0, tables not cleared, 726,667 mismatches on 20k records).
     Workaround in build_gl.sh: opt_expr; opt_dff -nodffe -nosdff after flatten (constant set/reset
     removed) and a check that fails the build if the pattern appears. Any CXXRTL simulation of these
     cell models without that step is invalid (this includes cg/gls/build_cxxrtl.sh, which copied the
     earlier recipe).
  2. The CXXRTL route then needed more than 7.5 GB and over an hour of g++ per netlist (OOM-killed at the
     7.6 GB limit); the first, unfixed build had taken 5 h 17 min. The co-simulation therefore uses
     Verilator (build_vl.sh) with a CXXRTL-API facade (mkshim.py), so the harness source stays the same.
     Build: 3-17 min, under 2 GB.
  3. Verilator models the cells' async reset as an event (negedge clr_); with rst_n low from the first
     eval, flops whose clock is gated off during reset were never reset (gated netlist only: ghr, thr,
     rstcnt, itc_v, use_alt not cleared). The PDK UDP is level-sensitive. mkshim.py settles the model
     once with rst_n = 1 so reset entry is an edge. The ungated netlists were unaffected (their flops see
     clock edges during reset).
  4. Routed SPEF from pnr/flow/def2spef.py: nets that are bits of an escaped bus (\ttag2[6] [1]) are
     written as ttag2\[6\]\[1\]; OpenSTA/OpenROAD expect ttag2\[6\][1] and drop them (STA-1650). 8112 of
     37,127 nets (v2 routed) and 7728 of 34,396 (v1 newsdc) get no parasitics in the flow's own STA.
     With the names fixed (sed in icarus_tb.sh), standalone sta, ss: v2 routed setup WNS -0.16 ns (flow
     -0.157), hold 0.21 ns (flow 0.183); v1 newsdc setup 0.02 ns (flow 0.019).

4. SDF-annotated simulation (v2 routed, slow corner ss_rcworst_1p08_125, 6.0 ns constraints)
   OpenSTA write_sdf with the name-fixed SPEF; sdffix.py for Icarus (no COND, one corner value);
   Icarus 12 -gspecify. Icarus 12 does not execute $setuphold/$width, so no timing-check violations can
   be reported; a timing problem can only show up as a functional failure.
   The directed testbench drives inputs and reads registered outputs at the same instant after each
   edge. In ss the registered outputs settle 3.51 ns after the clock pin edge (clk->f_ckpt; f_busy
   2.09 ns) while inputs must change no later than 2.86 ns after it (input->flop arrival 4.17 ns,
   capture 7.03 ns) and no earlier than 1.29 ns (hold). At a 6.0 ns back-to-back tick (4.0 low / 2.0
   high, sample 3.9 ns) 5 checks fail, all from the testbench sampling f_busy / f_ckpt 2.0 ns after the
   edge (f_busy seen for 65 cycles, then knock-on). With low 3.2 / high 3.7 / sample 5.7 ns (edges at
   least 6.9 ns apart) max and min delay runs both give "DONE: 0 failure(s), 3 known-open", logs
   identical to zero delay.
