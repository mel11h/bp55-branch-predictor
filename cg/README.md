# Clock gating for BP55 (hardened RTL): notes

Working notes of the clock-gating work. Scripts here and in `syn/run_cg/`, `pnr/run_v2_cg/`.
Bulky outputs (patched Liberty copies, simulation builds, stimulus records, SAIF) are
git-ignored and regenerated by the scripts.

## Quick start

```
cg/setup.sh          # writes cg/lib/: the three Liberty corners with the ICG cells completed, and the LEF workaround
source cg/env.sh     # BP55_LIBDIR and BP55_CELL_LEF for pnr/flow/run.sh, finish.sh and sta.sh
```

`cg/setup.sh` never modifies the PDK and checks the patched Liberty against the sha256 values in
`patch_liberty.log`. The main flow in `pnr/flow/` takes both overrides, so a gated netlist goes through
the same scripts as an ungated one; `pnr/run_v2_cg/scripts/` is the copy the runs below were made with.
Checked after the merge: `pnr/flow/sta.sh` gives the same slacks as before on the gated layout with the
overrides (ss +0.110 ns) and on the ungated layout without them (ss -0.157 ns). Placement, CTS and
routing were not re-run through the merged scripts.

## Diagnosis

Two separate defects were found. Only the second one broke place and route.

1. **Liberty (PDK, release v1.10.103): the ICG cells are not described as clock gates.**
   The ten cells ICGX{0P5,1,2,3,4}H7R and ICGNX{0P5,1,2,3,4}H7R carry
   `clock_gating_integrated_cell : "latch_posedge_postcontrol"` (ICGN: `latch_negedge_postcontrol`)
   but have no `clock_gate_clock_pin`, `clock_gate_enable_pin`, `clock_gate_out_pin`, no
   `statetable` and no `function`/`state_function` on ECK. The `_postcontrol` type also implies a
   test-control pin the cells do not have (Verilog model, CDL and LEF: CK|CKN, E, ECK only).
   Present and correct: `clock : true` on CK, `setup_rising`/`hold_rising` of E against CK, the
   CK->ECK `combinational positive_unate` arc, power tables.
   Real function (Verilog UDP `ipicg_latchnsr`, CDL): ICGX = latch transparent while CK is low,
   ECK = CK & latched E; ICGN = latch transparent while CKN is high, ECK = CKN | !latched E.
   Effect: `yosys clockgate -liberty` rejects every ICG ("missing clock_gate_clock_pin") and
   inserts none; commercial synthesis cannot infer gating either (upstream issue #15, open since
   2026-04-17). OpenSTA does not need the attributes: it already times E as a clock-gating check
   and propagates the clock through the CK->ECK arc (identical reports with both libraries).

2. **OpenROAD v2.0-17598 (Dec 2024) + LEF `USE CLOCK` on ECK: no clock tree behind any ICG.**
   `dbNet::getFirstOutput()` skips every pin whose LEF USE is CLOCK, and the PDK LEF (correctly)
   declares ECK as `USE CLOCK`. TritonCTS therefore sees every gated-clock net as driverless and
   prints `CTS-0122 Clock net "..." is skipped for CTS because it is not connected to any output
   instance pin` for all 366 ICG outputs. The gated flops get no buffering at all, so the gated
   leaves arrive late (slow-corner latency 0.86 to 2.79 ns, skew 1.93 ns) and the latency
   balancer can only pad the ungated tree to the average. Fixed upstream in OpenROAD PR #10549
   (commit a55161a17c, 2026-05-29). Reproduction: `pnr/run_v2_cg/repro_upstream_lib/2_cts.log`.

## Fixes

* `patch_liberty.py`: patched Liberty copies (`lib/`, three corners) with the missing
  attributes, latch state table and ECK state function; `liberty_patch_typ_tt.diff` is the
  resulting diff for one corner (the change proposed upstream).
* `patch_lef_icg_use.py`: flow workaround for the OpenROAD bug (ECK `USE SIGNAL` in a LEF copy).
  Not a PDK defect; not needed with OpenROAD >= a55161a17c.

## Functional checks

* `act/record.sh` + `act/replay.cpp` (Verilator, `act/build_vl.sh`): the RTL co-simulation
  (sim/cosim.cc, model checks active) records every cycle's inputs and outputs; the gate netlist
  replays them and every output is compared every cycle. All-zero initial state on both sides.
* `act/sweep_replay.sh`: all 21 traces, 60000 branch records each, MISS=1000 (u_isbr=0 training
  for every BTB-missing non-branch), STALL=100, FLUSH=50, SEED=2: `act/replay_sweep_syn_cg4.log`.
* `gls/xprop_gl.sh`: verif/tb_bp55_xprop.sv on a gate netlist (4-state, Icarus), PDK UDP models
  (`udp`) or the behavioural models of gls/mkcells.py (`gl`).
* Reset finding: async-reset flops behind an ICG (thr, use_alt, ...) get no clock edge while
  reset is low. Silicon is fine (RN is level-sensitive), but an edge-triggered behavioural model
  (`always @(posedge CK or negedge RN)`) misses a reset that is already low at time 0, and so does
  a Verilated model; the gated netlist then fails tb_bp55_xprop with the gl models unless reset is
  asserted with an edge (`--reset-edge`). With the PDK UDP models it passes unchanged.

## Hold fix on the routed cg2 layout (pnr/run_v2_cg/gated_cg2_eco)

`gated_cg2` missed hold by 10 ps in the fast corner on output f_meta[98]. `pnr/flow/5_eco_hold.tcl`
(hold repair with a 0.06 ns margin on the finished database, incremental routing) inserted 57 buffers.
Result with re-extracted wires: setup ss/tt/ff +0.110 / 1.894 / 2.603 ns, hold 0.037 / 0.044 / 0.043 ns,
0 router violations, 0 antenna violations, cell area 113562 um2. Cell-level LVS matches
(signoff/results/v2_cg2_eco: 29872 cells, 30160 nets). Replay of all 21 traces on the routed netlist:
act/replay_sweep_routed_cg2_eco.log, 27.8 M cycles, 0 mismatches. Power re-measured on the repaired layout
(power/routed_cg2_eco.log, SAIF from the repaired routed netlist, same windows): default 13.93 mW,
coremark 10.74 mW, nsichneu 10.86 mW; before the repair 13.92 / 10.74 / 10.86 mW.
